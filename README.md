# Cantamos 🎶 – ספרדית של ספרד בשירים, לכל המשפחה

אפליקציה משפחתית ללימוד ספרדית באמצעות שירים, מהקל אל הקשה.

## הפעלה

דרוש Node.js 22.5 ומעלה (משתמש ב-SQLite המובנה ב-Node).

```bash
npm install
npm run build
ADMIN_PASSWORD=הקוד_שלך npm start
```

נכנסים לכתובת http://localhost:3000.

| משתנה | משמעות | ברירת מחדל |
|---|---|---|
| `ADMIN_USERNAME` | שם המשתמש הקבוע של מנהל המערכת | `עדי טמיר` |
| `ADMIN_PASSWORD` | הקוד של המנהל (מתעדכן בכל הפעלה) | `1234` (כדאי לשנות) |
| `PORT` | פורט | `3000` |
| `DB_PATH` | קובץ מסד הנתונים | `data/cantamos.db` |

לפיתוח עם טעינה מחדש: `npm run dev` ואז http://localhost:5173.

כדי שכל המשפחה תוכל להיכנס מהטלפון, מעלים את השרת לשירות אירוח (Render / Railway / Fly.io) עם **דיסק קבוע** לתיקייה `data/`, או מריצים אותו על מחשב בבית ברשת הביתית.

## מה יש באפליקציה

- **משתמשים:** כל אחד יוצר לעצמו שם משתמש וקוד אישי. מנהל המערכת מוגדר מראש במשתני הסביבה.
- **שיר משפחתי אחד בכל פעם:** רק המנהל מקדם לשיר הבא. לשירים קודמים אפשר תמיד לחזור, וההיסטוריה של כל משתמש נשמרת.
- **השיר:** נגן ספוטיפיי מוטמע, והשורות מודגשות לפי התקדמות השיר. אפשר לעצור, לחזור על שורה, ללחוץ על שורה כדי לקפוץ אליה, ולהפעיל "עצירה אחרי כל שורה". יש תרגום לעברית ותעתיק עברי לכל שורה, וגם הקראה איטית בקול (קול es-ES של הדפדפן).
- **אוצר מילים:** חלוקה להברות, הדגשת ההברה המוטעמת, תעתיק עברי במבטא של ספרד, השמעה וטיפים להגייה.
- **דקדוק:** נושא דקדוקי לכל שיר, טבלאות הטיה ורקע תרבותי.
- **תרגול:** כרטיסיות, התאמה, השלמת מילה בשיר, סידור משפט, הבנת הנשמע, הטיית פעלים והגייה עם זיהוי דיבור (ב-Chrome).
- **מבחן:** כל שיר מקבל מבחן מעורב שנוצר אוטומטית. כל הניסיונות נשמרים.
- **המשפחה:** כרטיס לכל משתמש, גרף של ציון המבחן הטוב ביותר בכל שיר, וגרף נקודות.

## השירים

תוכנית הבסיס כוללת 10 שירים עממיים מספרד, שהם נחלת הכלל (`server/seedSongs.js`):

1. Al corro de la patata – ארטיקלים, מין ומספר
2. Los cuatro muleros – מספרים, ir, ‏al = a+el
3. La Tarara – צבעים, בגדים, tener / llevar
4. Vamos a contar mentiras – ‏ir a + שם פועל, הווה
5. Tengo una muñeca vestida de azul – מספרים, היכרות עם pretérito
6. Los peces en el río – ‏estar + gerundio, פעלים חוזרים
7. Campana sobre campana – ציווי, vosotros, עתיד
8. Anda jaleo – ‏indefinido מול imperfecto
9. Romance del Conde Olinos – סיפור בעבר
10. Asturias, patria querida – ‏subjuntivo

**שירים מודרניים** (Estopa, Maná, Mercedes Sosa, Muerdo ועוד) המנהל מוסיף באזור הניהול. ברשימת ההצעות יש לכל שיר רמה מוצעת. המילים מוגנות בזכויות יוצרים, ולכן המנהל מדביק אותן בעצמו יחד עם התרגום ואוצר המילים. התרגילים והמבחן נוצרים מהן אוטומטית.

### חיבור לספוטיפיי וסנכרון המילים
1. בעמוד השיר פותחים את "כלי מנהל" ומדביקים קישור לשיר מספוטיפיי (Share → Copy Song Link).
2. לוחצים "התחלת סנכרון". בכל פעם ששורה מתחילה להישמע, לוחצים על הכפתור או על מקש הרווח.
3. שומרים. מעכשיו המילים מודגשות אוטומטית לכל בני המשפחה.

> ספוטיפיי מנגן שיר מלא רק למי שמחובר לחשבון ספוטיפיי בדפדפן. בלי חיבור מתנגנת דוגמה של 30 שניות.
